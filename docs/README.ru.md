# Career Agent

Локальный прототип поиска вакансий и управления решениями. Интерфейс RU/EN и светлая/тёмная тема. Python 3.10+; дополнительных библиотек для запуска не требуется.

## Запуск из исходников

Запустите дашборд командой:

```bash
cd /path/to/ai-career-agent
python3 dashboard_server.py
```

Откройте в любом браузере http://127.0.0.1:8765. Остановка — Ctrl+C. `CAREER_PORT` меняет порт сервера.

## Профиль

В разделе «Профиль и источники» задаются имя, критерии, навыки, идентификаторы карьерных страниц компаний и список включённых источников. У каждого источника есть ссылка на документацию и указан режим подачи. Откройте оригинальную вакансию и подайте заявку самостоятельно на сайте площадки или работодателя; приложение не получает подтверждение и не отмечает заявку отправленной. Данные сохраняются в локальном `jobs.sqlite3` (в `.gitignore`). Роли и ключевые слова используются в поиске и предварительном скоринге; остальные поля хранятся для будущих версий и **пока не участвуют в финансовых фильтрах**. При подключении MCP клиент может получить доступ к профилю; резюме автоматически не загружается и не анализируется.

## Источники

### Как подключить поиск

1. Откройте «Профиль и источники» и укажите искомые роли и ключевые слова.
2. Для Remotive, Arbeitnow и Hacker News достаточно включить источник. Для поиска логин не требуется, личные аккаунты не подключаются.
3. Для Greenhouse, Lever, Ashby и SmartRecruiters откройте страницу вакансий конкретной компании и вставьте её URL или ID в соответствующее поле профиля. Например: `https://jobs.lever.co/leverdemo`, `https://jobs.ashbyhq.com/openai`. Несколько страниц разделяйте запятыми. Поддерживаются только стандартные публичные адреса этих площадок; собственные домены компаний и европейский адрес Lever пока не поддержаны.
4. Нажмите «Проверить» рядом с источником, затем нажмите «Сохранить настройки». Проверка использует введённые в форме адреса; за один раз проверяется не более пяти компаний на источник. Ответ без вакансий не подтверждает правильность ID: площадка может одинаково отвечать на пустую и неизвестную страницу.
5. Запустите поиск. Результаты — публичные вакансии; для отклика откройте оригинал. Авторизация и отправка через интерфейс Career Agent пока не поддерживаются.

HeadHunter временно исключён из активного поиска после HTTP 403 в проверенной сети; ранее сохранённые вакансии остаются в базе. Если HeadHunter возвращает 403, API недоступен из текущей сети или для текущего клиента. Программа не обходит это ограничение; попробуйте позже или проверьте доступность официального API. В Hacker News ищутся последние 20 job stories, а не комментарии Who is hiring.

При поиске используются Remotive, Arbeitnow, Hacker News (последние 20 job stories) и настроенные пользователем карьерные доски Greenhouse, Lever, Ashby, SmartRecruiters. В профиле укажите идентификаторы компаний, например Greenhouse: `anthropic`, Ashby: `openai`; пустые поля пропускаются. Подключения и условия каждого работодателя могут отличаться; доступность API может меняться. Не все результаты релевантны, зарплата, страна работы и пригодность требуют ручной проверки. При ограничении или отказе источника ошибка отображается, защита не обходится.

Остальные упоминавшиеся ранее источники, в том числе Habr Career, Работа России, LinkedIn, Indeed, Workday, Workable, Personio, Teamtailor, Jobicy и другие, **ещё не подключены**. Публикация наличия коннектора требует проверки технической работы и условий. API HH в исходной среде отвечал 403; интеграция не обеспечивает обход этого ограничения.

Оценка по ключевым словам не является оценкой CV, поэтому ей нельзя пользоваться как готовым решением. Одобрение и отклонение сохраняются локально и **не отправляют заявку**. Кнопка карандаша готовит редактируемый запрос для ручной вставки в Codex или Claude; раздел AI-агента отдельно запускает CLI для анализа. В настройках можно вручную включить периодический поиск с интервалом не менее 60 минут. Он действует только пока сервер запущен и выключается при перезапуске; автоматической отправки нет. Отслеживание ответов и автоматическая отправка не реализованы.

## Локальное подключение к Codex и Claude через MCP

Экспериментальный MCP-сервер позволяет подключённому AI-клиенту читать сохранённые вакансии, профиль и состояние источников, запускать поиск, запускать AI-анализ и управлять расписаниями. Управление требует запущенного дашборда. Расписание обычного поиска отключается при остановке; настройки AI-анализа сохраняются и применяются после запуска дашборда. MCP не изменяет решения и не отправляет отклики. Для основного дашборда зависимости по-прежнему не нужны; MCP требует дополнительно установленный официальный Python SDK (`requirements-mcp.txt`). Мост проверен с MCP SDK 1.29.0; проверка непосредственно внутри Codex и Claude ещё необходима.

После установки зависимости в используемое окружение, из каталога проекта на macOS или Linux можно зарегистрировать сервер отдельно в нужном клиенте:

```bash
codex mcp add career-agent -- python3 "$PWD/career_mcp.py"
claude mcp add --transport stdio --scope local career-agent -- python3 "$PWD/career_mcp.py"
```

Используйте тот Python, в котором установлен MCP SDK. Первая команда изменяет конфигурацию Codex, вторая — локальную конфигурацию Claude Code для проекта. Для чтения данных дашборд запускать не требуется; для поиска и управления расписаниями он должен работать. Для Windows путь и синтаксис команды зависят от оболочки и ещё не проверены.

Подключённый клиент технически может прочитать личный профиль и вакансии, запускать поиск и менять расписание; инструкции требовать запрос пользователя сами по себе не являются контролем доступа. При работе с моделью эти данные могут передаваться её провайдеру. Подключайте только доверенный клиент и проверяйте его настройки. MCP работает в направлении AI-клиент → Career Agent; браузерные отклики пока не реализованы.

## AI-анализ вакансий

Раздел «AI-агент» запускает установленный и авторизованный CLI Codex или Claude Code для анализа до 15 сохранённых вакансий и профиля. По выбору перед анализом выполняется поиск. Настройки и последние 20 результатов хранятся в локальной базе; результат может содержать личные данные. Включённое расписание восстанавливается после запуска дашборда, но во время выключенного приложения и сна компьютера задания не исполняются; пропущенные запуски не догоняются. По умолчанию расписание выключено. Перед запуском убедитесь, что выбранный провайдер может получить профиль и описания вакансий.

Анализ использует ограниченный набор инструментов CLI и не отправляет заявки. Это экспериментальная интеграция, которую нужно проверить с собственными установленными версиями CLI и авторизацией: модульные тесты используют имитацию модели, реальных запросов к провайдерам не выполняли. Работу с Agent Browser, автоматическую подачу, достоверное подтверждение работодателя и запуск, когда компьютер выключен, эта версия не предоставляет.

## Публикация и конфиденциальность

Не публикуйте SQLite-базы, резюме, фотографии, документы, секреты, логи и персональные результаты поиска. До публикации проверьте файлы командой `git status --short` после инициализации репозитория. Прежде чем объявлять продукт готовым к публичному использованию, необходима проверка безопасности, корректности источников и лицензий. Исходный код доступен по лицензии [MIT](../LICENSE).

python3 -m unittest discover -s tests

## Status of supported boards

The first integration pass was exercised against live APIs: Ashby (`openai`), Lever (`leverdemo`), Arbeitnow and Remotive returned data. SmartRecruiters returned jobs for `BoschGroup` and `Sportradar` in a live check. Search only retrieves the first page for paginated sources; company-board discovery, cross-source deduplication and a source-health dashboard are not yet implemented. Greenhouse/Lever/Ashby/SmartRecruiters require configured board IDs.


## Разрешённые способы подключения

| Источник | Поиск | Отклик |
|---|---|---|
| HH | Официальный API; в текущей сети возможен 403 | Ручной переход на HH; авторизация соискателя через OAuth и отправка API ещё не реализованы. |
| Greenhouse, Lever, Ashby, SmartRecruiters | Публичная доска выбранной компании | Оригинальная форма работодателя. Публичный поиск не предоставляет пользователю ключ работодателя или партнёра для отправки через API. |
| Remotive, Arbeitnow, Hacker News | Публичный feed/API | Переход по оригинальной ссылке; дальнейший путь задаёт площадка или работодатель. |

Связывание личных учётных записей с платформами и автоматическая подача ещё не реализованы. В частности, сторонняя автоматизация LinkedIn не входит в поддерживаемые способы подключения.

Запуск поиска или копирование запроса не отправляет отклик. При вставке профиля или резюме в Codex/Claude сведения могут быть переданы выбранному AI-провайдеру.
